# KGodel 0.14.0a1 developer preview

This alpha adds reusable local modules so agents can share facts, recursive rules, logical objects, and plans across files.

```sh
python -m kgodel init my-agent --template modular
python -m kgodel imports my-agent/agent.kg
python -m kgodel explain my-agent/agent.kg --file my-agent/queries.kgq
python -m kgodel run my-agent/agent.kg
```

The modular courier reaches its goal in four operations using inherited policies and a reusable travel plan. The dependency report shows included paths and source hashes. Shared modules load once; cycles, name collisions, and paths outside the entry directory are rejected.

All file-based language commands load modules. Python integrations can use `kgodel.loading.parse_file` or `load_project`; the existing text parser remains free of filesystem reads. Saved sessions embed the combined program and resume without the original files. Schema 5 and reading schemas 1–5 are unchanged.

The release kit includes three starters, five demos, ten tutorials, and the module reference. Download the wheel or starter-kit ZIP and follow `START_HERE.md`. Python 3.10+ is required; there are no runtime dependencies or API keys.

This remains an alpha preview with shared logical names, not a full Prolog module system. It adds no namespace isolation, URL imports, automatic package downloads, or live reload. File-loading limits now apply to all CLI program inputs; see the module reference for defaults and Python overrides. Public release and PyPI publication are separate owner-controlled steps.

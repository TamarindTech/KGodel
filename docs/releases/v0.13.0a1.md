# KGodel 0.13.0a1 developer preview

KGodel is a local tool for exploring agents that explain decisions and revise beliefs. This alpha packages its Prolog-inspired reasoning, Smalltalk-style logical objects, planning, and saved sessions for early users.

## Start here

Download `kgodel-0.13.0a1-starter-kit.zip`, extract it, and follow `START_HERE.md`. It includes the installer, examples, tutorials, and source. Python 3.10+ with venv/pip is required; no API keys or runtime dependencies are needed.

Or install `kgodel-0.13.0a1-py3-none-any.whl` into your chosen environment, then run:

```sh
python -m kgodel doctor
python -m kgodel init my-agent
python -m kgodel run my-agent/agent.kg
```

Use `--template logic` with `init` for a pure knowledge base. Both starters include a README and runnable query file.

## Included

- Ground equality, inequality, and ordering filters with proof evidence.
- Installation diagnostics and starter projects that work outside the source checkout.
- Input-file protection for command-line exports and readable invalid-encoding errors.
- Five demos, nine tutorials, references, and schema-5 checkpoints with schemas 1–5 readable.
- Source and wheel distributions, starter kit, SHA-256 checksums, and a release manifest.

Release checks exercise language behavior, tutorials, packaging, and isolated installation on Windows, Linux, and macOS with Python 3.10 and 3.13. See the associated Actions run for exact results.

## Preview limits

This alpha is for experimentation and feedback. APIs may change before 1.0. It is not full Prolog or Smalltalk, and its environment is a local route simulator. There is no graphical app, hosted service, LLM integration, or arbitrary external-tool connector. PyPI publication is separate; use the attached wheel or starter kit.

Report reproducible issues through [GitHub](https://github.com/TamarindTech/KGodel/issues). Review filesystem paths before sharing `doctor --json` diagnostics.
